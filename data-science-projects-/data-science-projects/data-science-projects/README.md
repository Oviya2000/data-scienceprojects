# Project folders

See the [main project index](../README.md) for installation and one-command execution.

- [Telco churn prediction](telco_churn_prediction): validation-based model and threshold selection, then held-out test reporting.
- [Retail SQL analytics](retail_sql_analytics): ten executable SQLite queries and generated CSVs.
- [HR dashboard](hr_attrition_dashboard): constrained synthetic data, EDA, and a single-file offline dashboard.
- [Weather ETL](weather_etl_aws): explicit mock/live modes, validation, Parquet partitions, and local failure-path checks.

Customer and employee data is synthetic. No Power BI Desktop report or AWS deployment is represented as complete.
